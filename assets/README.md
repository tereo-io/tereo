# Brand assets

| File | Use |
|---|---|
| `tereo-banner.svg` | 1200×500, the README header |
| `tereo-mark.svg` | 256×256, avatars and the social preview |
| `tereo-favicon.svg` | 256×256 with heavier lines, for 16–32 px |

The wordmark and tagline are converted to outlines, so the SVGs need no fonts installed. The
typefaces are Michroma and Montserrat (SIL Open Font License).
