The provisioning document types gain the `branding` block: `BrandingProvisioning` (`default` and per-client `clients`, keyed by `clientId`), `BrandingProfileProvisioning` (the text, `layout`, `footerLinks`, `applyToConsole` and image path slots, every one optional) and `BrandingColorVariable`, the list of colour variables a profile may set.
